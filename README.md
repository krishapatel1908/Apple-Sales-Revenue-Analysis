# Apple Sales Analysis Dashboard

Project Overview

This project focuses on analyzing Apple sales data using **Power BI**. The dashboard provides an interactive view of sales performance, revenue, product trends, and other key business insights.

Objectives

* Analyze overall sales and revenue performance
* Identify top-performing Apple products
* Understand sales trends
* Compare product performance
* Create interactive and easy-to-understand visualizations
* Generate useful business insights from the data

Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Excel / CSV Dataset**

Dashboard

The Power BI dashboard includes interactive visuals for:

* Total Sales
* Total Revenue
* Product-wise Performance
* Sales Trends
* Top Products
* Category / Product Analysis
* Key Performance Indicators (KPIs)

Key Analysis

The project covers:

1. Data Cleaning and Transformation
2. Data Modeling
3. DAX Calculations
4. Exploratory Data Analysis
5. Interactive Dashboard Creation
6. Business Insights

Skills Demonstrated

* Data Cleaning
* Data Transformation
* Data Visualization
* Power BI Dashboard Development
* DAX
* Data Analysis
* Business Intelligence

Project Files

* `Apple Sales Analysis.pbix` – Power BI dashboard
* `Dataset` – Source data used for analysis

 Conclusion

This project demonstrates how sales data can be transformed into an interactive Power BI dashboard to understand business performance and identify meaningful trends and insights.
